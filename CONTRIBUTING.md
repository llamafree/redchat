# Contributing to REDChat

Thank you for your interest in contributing to **REDChat**!

## How to Contribute

1. **Fork the Repository**: Create your feature branch (`git checkout -b feature/AmazingFeature`).
2. **Follow Kotlin Style Guide**: Ensure strict compliance with standard Kotlin coding standards.
3. **Run Unit Tests**: Verify unit and Robolectric test suite prior to submitting pull requests (`./gradlew :app:testDebugUnitTest`).
4. **Submit Pull Request**: Provide a detailed summary of changes and architectural implications.

## Code Review Process
All submissions require approval from maintainers at **Llama AI SAS** and **Walluu SAS**.
