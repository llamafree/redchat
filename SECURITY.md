# Security Policy

## Reporting Vulnerabilities

Security is the highest priority for **REDChat**. If you discover a vulnerability or potential cryptographic flaw, please report it privately.

**DO NOT** open a public GitHub issue for security vulnerabilities.

### Contact
- Email: `security@llamaai.co` / `security@walluu.co`
- Response Time: Within 24 hours.

## Cryptographic Standards
- Asymmetric Key Exchange: X25519 (Curve25519)
- Digital Signatures: Ed25519
- Symmetric Encryption: AES-256-GCM
- Key Derivation: Argon2id
- RAM Sanitization: Zeroization on emergency wipe or session termination
