# Changelog

All notable changes to the **REDChat** project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-07-25

### Added
- **BLE Mesh Core Engine**: Decentralized multi-hop Bluetooth Low Energy flooding network.
- **Onion Routing Integration**: Simulated Tor node manager with dynamic latency metrics and node rotation.
- **Cryptographic Security Engine**:
  - X25519 Diffie-Hellman key exchange session management.
  - AES-256-GCM symmetric message encryption.
  - Ed25519 digital signature validation.
  - Argon2id key derivation for protected channels.
- **Cover Traffic Generator**: Configurable decoy packet generation to resist traffic volume analysis.
- **Volatile In-Memory Messaging**: RAM-backed state management with instant Emergency Wipe capability.
- **Material Design 3 Theme**: High-contrast dark professional canvas ("Professional Polish").
- **Slash Commands Suite**: Embedded CLI parser (`/j`, `/m`, `/w`, `/channels`, `/block`, `/unblock`, `/clear`, `/pass`, `/transfer`, `/save`).
- **Foreground Mesh Service**: Persistent Android foreground service with sticky notification.
- **Diagnostics Terminal**: Real-time log console with event filter and clipboard export.
